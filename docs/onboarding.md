# Onboarding

## Primeros pasos

1. Instala dependencias: `npm install`
2. Copia variables: `cp .env.example .env`
3. Arranca en desarrollo: `npm run dev`
4. Ejecuta checks: `npm run lint && npm test`

## Comandos útiles

- `npm run dev`
- `npm run build`
- `npm run lint`
- `npm run format`
- `npm test`
