# Contributing

## Flujo de ramas

- `feature/<nombre>` para nuevas funcionalidades
- `fix/<nombre>` para correcciones

## Commits

Usar Conventional Commits:

- `feat: ...`
- `fix: ...`
- `docs: ...`
- `chore: ...`

## Checklist de PR

- [ ] Código formateado
- [ ] Lint en verde
- [ ] Tests en verde
- [ ] Documentación actualizada
