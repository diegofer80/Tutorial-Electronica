# Tutorial-Electronica

Plantilla base para un proyecto backend con **Node.js + Express + TypeScript**.

## Requisitos

- Node.js 20+
- npm 10+

## Instalación

```bash
npm install
```

## Desarrollo

```bash
npm run dev
```

## Build

```bash
npm run build
npm start
```

## Calidad

```bash
npm run lint
npm run format
npm test
```

## Estructura

```txt
src/
  app.ts
  server.ts
  routes/
  config/
tests/
docs/
```
